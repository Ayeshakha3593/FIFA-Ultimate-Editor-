## 📝 How to use the editor
The layout follows a standard explorer format. You see your game files on the left and editing tools on the right.

### Editing Textures
You change kit colors, flag designs, or grass textures inside this menu. Click the "Texture" tab to browse game images. Choose an image, select "Export" to save it to your desktop, and open it in your preferred paint program. After you make your changes, use the "Import" button to put the new image back into the game file list.

### Updating the Database
The database menu handles player stats and team names. Select the "Database" icon from the top ribbon. The editor shows a table with rows and columns. Click any cell to type a new value. Remember to press "Save" before you close the window to ensure your changes go into the game.

### Managing 3D Models
The "Mesh" section allows you to change hair styles or face shapes. This part of the tool requires you to load a 3D file format. Choose your file and use the "Replace" button to swap old models for new ones. 

## 💡 Tips for better modding
*   Always keep a backup of your original game files before you start.
*   Make one small change at a time rather than changing everything at once. 
*   Test your game after every change to identify errors if they occur.
*   Check the file extension to make sure you use the right format for the type of edit you perform.

## 🚩 Solving common problems
If the application crashes, verify that your game path points to the correct folder on your drive. Close the game before you run the editor to prevent file access conflicts. If the editor does not start, install the latest version of the .NET Framework from the Microsoft website. Reach out to the support community if you experience issues that these common steps do not solve.
